4. Perform multiple logistic regression.

Use the glm function, ensuring that the habitat types (e.g. HabitatCode) are treated as categorical variables by converting them to factors.

################################################################################
##  Multiple logistic regression models the relationship between two/more (2/+)
##  predictor variables against one (1) binary (base-2) response variable.
################################################################################

x1 <- factor(deer_df$Habitat)
x2 <- deer_df$AverageDistance
y  <- deer_df$Detected

deer_glm_df <- data.frame(x1, x2, y)
deer_glm    <- stats::glm(y ~ x1 + x2, family=binomial, data=deer_glm_df)
## Warning: glm.fit: fitted probabilities numerically 0 or 1
## occurred
################################################################################
##  Calculate the predicted probabilities, holding the predictor x2 constant.
##
##  Since `x1` is already a `factor`, we don't need to worry about the range of
##  values and their corresponding labels.
################################################################################
x1_df      <- data.frame(x1, x2=mean(x2))
x1_df$prob <- predict(deer_glm, newdata=x1_df, type="response")


################################################################################
##  Calculate the predicted probabilities of x2 (Average Distance), holding each
##  level of the predictor x1 (Habitat) constant.
################################################################################
predict_x2 <- function(habitat) {
  x1_orig  <- x1
  x1       <- rep(habitat, length(x2))
  df       <- data.frame(x1_orig, x1, x2)
  df$prob  <- predict(deer_glm, newdata=df, type="response")
  return(df)
}

x2_df <- data.frame(x1)
for (habitat in levels(x1)) {
  x2_df[[habitat]] <- predict_x2(habitat)
}

Examination of results

i.) Detection probability of mean distance per habitat type

Holding the average distance constant by getting its average, the plot tells us that the Philippine Mouse-deer is absent (y=0) in the ASG (x1=1) and CVT (x1=2) habitats surveyed. The deer is present in ESG (x1=3) and OGF (x1=4).

The probability line, in red, shows that, at the average of the mean distances (mean(x2)=4.49), then the habitats ASG, CVT, and ESG have almost 100% (y>0.99) detection probability while OGF has an almost 0% (y<2e-10) detection probability.

These results are interesting because both ASG and CVT have no instances of the deer recorded yet were determine to have an almost 100% detection probability. Also, OGF has one (1) instance (x2=11.6) yet has 0% detection probability. This may have to do with the fact the average (x=4.49) was what we used to hold the average distance constant. At a glance I would say that 0.0 is “closer” to 4.49 than 11.66, which may explain why the model calculated a nonzero detection probability.

ii.) Detection probability of each habitat type per average distance

For each habitat type, each particular type was held constant when calculating the probabilities for the average distances. That is, a logistic regression curve plot was generated for Average distance x Detection probability holding one habitat type, for example ASG, constant. This process was repeated for the other habitat types with new plots.

Habitat types ASG, CVT, and ESG all resulted in the same plot. The sampling points with distances of 0.0 (x2=0.0) all had a near 0% (prob=7.88e-12) detection probability. However, at distances of 7.3 (x2=7.3) and 11.6 (x2=11.6) the detection probability was 100% (prob=1.0). Like in the previous plot, this was expected for ESG, but not for ASG and CVT.

The only different plot was one with OGF. It differed only in the detection probabilities of distances of 7.3 (x2=0.0). The detection probability for this was almost 0% (prob < 2.22e-16) instead of 100% as in the first three (3) plots.
